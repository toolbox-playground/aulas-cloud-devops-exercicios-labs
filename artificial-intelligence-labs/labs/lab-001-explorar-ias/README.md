# Lab 001 - Explorar IAs

## Objetivo

Comparar 3 modelos de IA diferentes executando a mesma tarefa.

## Dificuldade e tempo

- Dificuldade: Iniciante
- Tempo estimado: 20 a 30 minutos

## Propósito

Evidenciar que vale explorar múltiplas IAs para objetivos diferentes.

## Ferramentas sugeridas

- ChatGPT
- Gemini
- Kimi (ou outro modelo equivalente)

## Passo a passo

1. Abra três IAs diferentes em abas separadas.
2. Use o mesmo prompt base em cada IA.
3. Salve o resultado de cada uma (texto, link compartilhado ou arquivo).
4. Compare qualidade, clareza, estrutura e fidelidade do conteúdo.
5. Registre qual IA foi melhor para o seu objetivo.

## Prompt do lab

```text
Refaça os slides desta apresentação em anexo para uma aula de DevAIOps, mantendo uma estrutura didática para aula ao vivo. Inclua: histórico e futuro da IA, GenAI/LLMs, agentes de IA para produtividade e MCP. Organize em tópicos claros, com linguagem simples e objetiva.
```
