## 📦 1. Helm (gerenciamento de aplicações)

O Helm é o **gerenciador de pacotes do Kubernetes**.

Ele permite:

- Instalar aplicações complexas com 1 comando
- Reutilizar templates
- Versionar deploys

Exemplo:
```bash
helm install meu-app chart/
```

---

## 🌐 2. Ingress (acesso web real)

Até agora você usou NodePort.

O Ingress permite:

- URLs reais (ex: app.tbxtech.com)
- HTTPS
- Roteamento inteligente
